Install

Five steps. You do not need to understand them all to follow them. If something goes wrong, nothing is broken: setup can be run again, and it skips what is already done and never overwrites your settings files.

Step 1: Install three programs

Othos is built on three free programs. Install each one the usual way (download, open, click through the installer).

ProgramWhat it isGet it
Python 3.12The language Othos's voice agent is written in. It must be version 3.12.x. Newer versions (3.13 and later) do not work yet, even if they are the one on the download button.python.org/downloads. In the installer, tick py launcher.
Node.js (LTS)Runs the web page you talk to Othos on. Pick the one marked LTS.nodejs.org
OllamaThe program that runs AI models on your PC.ollama.com/download

Optional: Git, only if you want to get updates the developer's way. You can skip it.

Step 2: Run setup

Easiest: use the setup window. If your Othos folder contains OthosSetup.exe, double-click it and follow the buttons. It checks that the three programs above are installed (listing any that are missing, with a link each), then does the same work as the command below and shows each step. If your folder has only an installer folder with source files, see Advanced, or use the command below instead.

Or: type one command.

  1. Open the Othos folder in File Explorer (the one containing setup.ps1).
  2. Click the long address bar at the top of the window, type powershell, and press Enter. A blue or black window opens. This is PowerShell, a place where you type instructions to the computer.
  3. Type (or paste) this and press Enter: 
    powershell -ExecutionPolicy Bypass -File setup.ps1
    (The -ExecutionPolicy Bypass part just lets this one script run. It changes no Windows settings.)

Setup asks Which setup? Type 1 (mixed, the usual one) or just press Enter. Then it works through these steps and prints a line starting with == for each:

  • Checking tools: looks for Python 3.12, Node, Ollama, and installs a small helper called pnpm if it is missing.
  • LiveKit server: downloads the small program that carries your voice between the web page and Othos. It comes from LiveKit's official download page.
  • Python environment: installs the packages Othos needs, into a folder of its own that does not touch the rest of your PC.
  • Call page: installs the web page you will talk on.
  • Models: downloads four small AI models through Ollama, about 6 GB in total. This is the longest step and can take a while on a slow connection.
  • Your settings: makes three files for you to fill in (next step). It also asks what you would like to call your assistant. Press Enter to keep the name Othos.

If setup stops, the last line starts with STOP: and says what is missing, for example Python 3.12 not found. Install what it names, close and reopen PowerShell, and run the same command again. It carries on where it left off.

Step 3: Fill in your settings files

When setup finishes, three files open in Notepad++ (if you have it) or Notepad. They live in the agent folder and stay on your computer.

  • .env: your keys. For the usual setup you need two: DEEPGRAM_API_KEY (turns your voice into text) and RIME_API_KEY (Othos's speaking voice). Sign up on each service's website, copy the key, and paste it after the = sign. Treat keys like passwords: never post them or send them to anyone. Leave every other line as it is.
  • personal.json: your name and town, so Othos can greet you and give local weather. Everything starts empty, which just switches that feature off. See Make it yours.
  • profile.md: a few plain sentences about you and how you like Othos to behave, such as "Keep answers short." Only you edit this file.

Save each file (Ctrl+S) and close it.

Step 4: Check that everything is ready

In the same PowerShell window, run:

powershell -ExecutionPolicy Bypass -File doctor.ps1

It prints a line for each thing it checked. Lines starting ok are fine. Lines starting FIX say what is missing or wrong. At the end you see All good. or the number of things to fix. It only looks; it never changes anything.

Step 5: Start Othos

Double-click start-othos.bat in the Othos folder. Your web browser opens the call page at http://127.0.0.1:3000 (that address means "this computer"). Now go to Your first call.

Optional: a taskbar app

If you would rather click an icon than a .bat file, build the Othos app once. In PowerShell, in the Othos folder:

powershell -ExecutionPolicy Bypass -File agent\build-othos-app.ps1

This adds an Othos shortcut. Click it to start Othos; close its window to stop Othos. The first time it opens, it asks whether it may check your PC's specs. If you say yes, it shows which AI models and settings fit your PC. Nothing leaves your computer.

To stop Othos without the app, run agent\stop-othos.bat.

Advanced: setup options and what it downloads
  • setup.ps1 -Mode offline picks the offline setup without asking.
  • The four models are llama3.2:3b (conversation), nomic-embed-text (searching your notes), moondream:1.8b (the camera) and qwen2.5-coder:3b (The Smithy and the code chat).
  • If you use Git, setup also turns on a pre-commit check that keeps requirements.txt an exact list of package versions.
  • If Microsoft Defender is running, setup scans the LiveKit download before using it.
