About this guide

How far to trust it, and where Othos comes from.

How this guide was checked

Every page was written for someone who has never used Othos or a voice assistant before. The facts come from the project's own files. Here is what that means in practice:

  • Checked against the setup and checker scripts: the steps and questions setup asks, the four models it downloads, the three settings files it makes, the STOP: messages, the lines doctor.ps1 prints, and that start-othos.bat starts Othos. Setup was also tried on a clean Windows test machine with nothing installed, where it stopped at "Python 3.12 not found" as described.
  • Taken from the project README and not re-tested for this guide: the voice commands, news and weather sources, The Smithy's task types, the privacy table, the hardware advice and the offline speech steps. If a command does not work the way a page says, please report it.
  • Known to be untested: fully offline speech has only been checked to start up, never used in a real call.

Figures such as download sizes and speeds are approximate and can change.

Updates

Othos is updated from time to time, and this guide is updated with it. The project's README lists what changed in each version.
