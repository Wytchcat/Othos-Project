The Smithy

The Smithy is a helper that writes and reviews computer code in the background, while you do other things. You do not need to know how to code to try it, but it is most useful if you do.

The safety rule: everything The Smithy makes is a draft, a file for you to read. It never applies a change, runs a program, sends anything or installs anything. You look at the result and copy what you want yourself.

Set it up (once)

  1. Finish Install first. The Smithy uses the same Python environment, and Ollama must be installed.
  2. Build its app. In PowerShell, in the Othos folder: 
    powershell -ExecutionPolicy Bypass -File agent\build-smithy.ps1
    This adds The Smithy to your Desktop and Start menu. (Setup does not do this for you.)
  3. Open The Smithy from the shortcut. Opening it starts the helper; closing it stops it.
  4. Click Get models... and fetch the default coding model (qwen2.5-coder:3b) if setup did not already download it. Ollama must be running.

Ask it for something

With Othos running, say:

  • "Ask the Smithy to review gaming dot py."
  • "Ask the Smithy to write a script that renames my photos by date."
  • "Ask the Smithy to build a small to-do web app."

The result waits in agent\drafts\smithy\. Othos tells you when one is ready ("Smithy task 3 is ready").

You sayWhat happens
"What's the Smithy working on?"Tells you the progress.
"Read me Smithy task 3" / "show me Smithy task 3"Reads the result aloud, or opens it.
"Keep Smithy task 3" / "discard Smithy task 3"Marks the result. Othos asks you to say yes or no first.
"Read me the Smithy log" / "show me the Smithy log"The work log.

What it can do

  • Review: read a code file and list bugs and risks.
  • Fix: draft a fix as a "diff" (a list of changes). It is never applied.
  • Script: write a script. It is saved, never run.
  • Joomla: draft Joomla website template changes.
  • Build: make a small project from scratch, in its own folder under agent\drafts\smithy\.
  • Follow-up: ask a question about an earlier result, or ask for a new version of a build.

While it works, Progress (a small window beside the work log) shows each step as it happens.

What it is allowed to read

It reads files only from the folders you list as code_folders in agent\smithy.json. Private files (.env, keys, your notes) are always blocked, and anything that looks like a key is removed before text reaches a model. This is enforced by the program's code, not by asking the model nicely.

How it runs on your PC

  • It uses your computer's main processor (CPU) only and its own small model, so it is slow but does not need a graphics card.
  • It pauses while a processor-heavy game is running.
  • A typed code chat is also at http://127.0.0.1:3000/code (or the </> button during a call). Save code to drafts writes new files into agent\drafts\ and changes nothing else.
Advanced: using bigger models from online providers

A provider is an online company that runs a larger AI model. In The Smithy's window, Providers... lets you add a provider's key (stored encrypted for your Windows account, outside the Othos folder) and turn the provider on.

  • Nothing leaves your PC until you turn a provider on. All are off by default.
  • What is sent is that task's request, after the same filter that removes personal details.
  • Providers whose free plans may train on what you send are refused unless you allow them.
  • There are daily token and spending limits. LM Studio running on your own computer works the same way and sends nothing out.
  • With more than one provider on, The Smithy can switch to the next when one runs out of free use, and falls back to your own PC last.

Full details, including the command line and settings, are in agent\SMITHY.md.
