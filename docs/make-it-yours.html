Make it yours

Othos works out of the box. Everything on this page is optional: it just makes Othos feel like yours.

All these settings live in the agent folder, in files that stay on your computer. Edit them with Notepad. After saving a change, close and reopen Othos. (For the call page, refreshing the web page is enough.)

Your name and town: personal.json

Open agent\personal.json. Every field starts empty (""), which simply means that feature is off. Type your answer between the quote marks. Keep the quote marks and commas as they are.

FieldWhat it doesExample
nameWhat Othos calls you (in greetings, goodbyes and urgent moments)."Alex"
weather_locationYour town, for the weather and "where do I live?"."Anytown, State, US"
weather_latlonYour town's map point, used for US National Weather Service forecasts. Only this is sent to the weather service, not your name."40.7128,-74.0060"
contact_urlYour website or contact page. Wikipedia refuses programs that do not give one, so Wikipedia answers stay off until you set it."https://example.com"
pronunciationsHow Othos's voice should say local place names it gets wrong.{"Anytown": "Any-town"}

The file also has fields for local and state news feeds, extra names the microphone keeps mishearing (keyterms), and the weekly model check. The bottom of the file has an _example section showing a filled-in file for a made-up person. It is never used.

Weather comes from the US National Weather Service. Outside the US, Othos falls back to a web search for your town's weather.

A few lines about you: profile.md

agent\profile.md is a plain text file where you write a few lines about yourself and how you like Othos to behave. For example:

Keep answers to one or two sentences unless asked for more.
I'm vegetarian.
I live with two cats.

Othos reads it at the start of each call. Othos never writes to it; only you do.

Give your assistant its own name, logo and colour

Your assistant does not have to be called Othos. Setup asks what to call it, or you can change it later in the assistant section of personal.json:

"assistant": {"name": "Jarvis", "heard_as": ["Jervis"], "logo": "my-logo.png", "color": "#9d7bff"}
FieldWhat it does
nameWhat the assistant calls itself, and the name you say to it ("Jarvis, end the call"). Empty means Othos.
heard_asWords the microphone writes down instead of the name, so they count as the name too. Look in a call's transcript to find them.
logoA picture file: a full path, or a file name inside the agent folder. PNG, SVG, JPG, WebP and ICO work on the call page. For the taskbar and shortcut icon, use an .ico file and run agent\build-othos-app.ps1 again.
colorAn accent colour for the name, such as "#9d7bff". Empty means the usual colours.

The circuit-board picture on the call page stays the same; only the name on it changes.

Advanced: more personal.json fields
  • home_location: where you live, if different from the weather town.
  • local_news.feeds and state_news.feeds: RSS feeds (a site's list of new articles) used for "local news" and "state news". Each has a site, a spoken name, a url and an optional skip_urls pattern. Trigger words (trigger_words) say which spoken words mean local or state news.
  • keyterms: names the microphone keeps getting wrong.
  • model_check: "ask" (a Yes/No once a week, the default), "auto" or "off". See Advanced.
