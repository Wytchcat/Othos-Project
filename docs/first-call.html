Your first call

A "call" is just a conversation with Othos. You start it on a web page that runs on your own PC.

Start a call

  1. Start Othos. Double-click start-othos.bat in the Othos folder, or click the Othos shortcut if you built the taskbar app. Give it a few seconds: it starts several small programs in the background.
  2. The call page opens in your web browser at http://127.0.0.1:3000. If it does not open by itself, type that address into your browser yourself.
  3. Press Start call. Your browser may ask permission to use your microphone. Choose Allow, or Othos cannot hear you.
  4. Say hello. Othos greets you out loud. Talk the way you would to a person. When you stop, it answers.

Nothing happens, or Othos does not answer? It may still be loading. Wait a few seconds and press Start call again. If it still does not work, see Fixing problems.

Things to try

  • "What's the weather like?" (needs your town in your settings)
  • "Remember that my sister's birthday is June 3rd." Then later: "What did I tell you about my sister?"
  • "What's the news?" Then: "Keep going."

More ideas are on Everyday use.

End the call

Say "Othos, end the call" or "hang up". Othos says goodbye and ends the call.

Stop Othos

When you are finished, stop the background programs so they stop using your PC:

  • If you use the taskbar app: close the Othos window.
  • If you started it with start-othos.bat: run agent\stop-othos.bat.
Advanced: what is running while Othos is on

Starting Othos starts four small servers, all listening only on your own PC (127.0.0.1), so other devices on your network cannot reach them:

  • the LiveKit call server on port 7880,
  • the voice agent on port 8081,
  • the call page on port 3000,
  • Ollama on port 11434.

The agent's log is agent\logs\agent.log. Logs can include what you said, so keep them private.
