Fixing problems

Start with the first item. It finds most problems.

First: run the checker

Open PowerShell in the Othos folder (open the folder in File Explorer, click the address bar, type powershell, press Enter) and run:

powershell -ExecutionPolicy Bypass -File doctor.ps1

Lines starting FIX tell you what is missing or wrong: a key, a model, a program, a busy "port", or an address written as localhost instead of 127.0.0.1. Fix those, then run it again until it says All good. It only looks; it changes nothing.

Common problems

Othos did not join the call, or never answers

  • Give it a few seconds, then press Start call again. It may still be loading.
  • Is Ollama running? Othos needs it for thinking.
  • The address LIVEKIT_URL must be the same in agent\.env and the call page's .env.local.
  • If it says an older copy is still running (port 8081 busy), run agent\stop-othos.bat, then start again.
  • Look at the last lines of agent\logs\agent.log for a clue. It is private: do not post it.

The page will not open

Type http://127.0.0.1:3000 yourself. Always use 127.0.0.1, not localhost: on some Windows setups localhost goes to the wrong kind of address and nothing answers. Every address in your settings should use 127.0.0.1.

"Python 3.12 not found", or a wrong Python

The agent needs Python 3.12.x. Newer versions do not work. Install 3.12 (and tick py launcher). If doctor.ps1 still complains, delete the agent\.venv folder and run setup again.

A port is busy

A "port" is a numbered door a program listens on. Othos uses 7880 (call server), 8081 (agent), 3000 (call page) and 11434 (Ollama); offline speech also uses 8000 and 8880. If another program, or an old copy of Othos, holds one, close it or run agent\stop-othos.bat.

Replies are slow

  • Close other heavy programs.
  • Use a smaller conversation model (OLLAMA_MODEL in agent\.env).
  • Turn off the moving circuit-board picture by opening http://127.0.0.1:3000/?board=off.
  • Expect a few seconds before the first word on a PC without a graphics card. That is normal.

Setup stopped with STOP:

Read the line: it names what is missing. Install it, close and reopen PowerShell, and run setup again. See Install.

Strange "401" or LiveKit Cloud messages in the log

Harmless. Some plug-ins try an online service Othos does not use; it uses its own local server.
