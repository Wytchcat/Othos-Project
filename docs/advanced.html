Advanced

Everything here is optional. You can use Othos for a long time without opening this page. Each part says what it is for.

The settings file: agent\.env

Setup makes agent\.env from .env.example. It stays on your computer. Anything not marked "needed" can stay empty.

SettingWhat it isNeeded?
OTHOS_SPEECHcloud (mixed) or local (fully offline).Yes (setup sets it)
DEEPGRAM_API_KEYTurns your voice into text. Sign up at console.deepgram.com.Mixed mode
DEEPGRAM_MIP_OPT_OUTtrue asks Deepgram not to use your audio to train its models.Keep true

The call page has its own small file, ui\.env.local, which setup makes. It repeats the three LiveKit lines and sets OTHOS_CODE_MODEL (the model for the code chat).

Fully offline speech

Instead of Deepgram and Rime, speech can run on your PC. You need a graphics card (about 2 to 3 GB of graphics memory for speech, on top of the conversation model) and two extra programs.

  1. Run setup.ps1 -Mode offline. It sets OTHOS_SPEECH=local.
  2. Install and start two speech programs, following their own instructions:
    • Speaches (hearing you) on http://127.0.0.1:8000, with a Whisper model such as Systran/faster-whisper-small.en.
    • Kokoro-FastAPI (the voice) on http://127.0.0.1:8880.
  3. If yours use other addresses, set LOCAL_STT_URL, LOCAL_STT_MODEL, LOCAL_TTS_URL and LOCAL_TTS_VOICE in agent\.env.
  4. Start both before Othos. doctor.ps1 checks they are listening.

Not tested in a real call yet. Local speech was built on a PC with no graphics card, so it has only been checked to start up. Web search is off in this mode unless you add a Tavily key.

The optional setup window

The installer folder holds the source for OthosSetup.exe, a window that does what setup.ps1 does. You build it once with the C# compiler that comes with Windows, so there is nothing extra to install:

powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1

This makes installer\OthosSetup.exe. Move it into the Othos folder, next to agent and ui (it looks for both), then open it.

  • You can resize the window, and its messages use the same colours as the window.
  • The window itself never uses the internet; the downloads are done by setup.ps1.
  • If a step stops, the message says which step and shows the error line. Install what it names, then press Try Again.
  • After a good install it asks one optional question, "Connect your Google account?", with the benefits and risks. Not now is the default. It makes no network call and only saves your answer on your PC.

The weekly model check

AI models improve. Once a week the Othos window asks "Check for updated models?" (Yes, check or Not now). Check models... runs it any time. You can change how it starts with model_check in personal.json: "ask", "auto" or "off".

  • The check itself downloads nothing. It lists models tested with your version, newer ones in the same families (marked "not tested yet"), and a newer Ollama if there is one.
  • Each model is marked Fits, Tight or Won't fit for your PC's memory and graphics card.
  • To get one, click Get. A Yes/No shows the download size and free space first. Nothing downloads until you click Yes, download.

Which models suit your PC?

Bigger models give better answers but need more memory and a graphics card. As a rough guide:

  • Any 16 GB PC, no graphics card: the small default models, in mixed mode. Replies take a few seconds to start, and writing is slow (an estimated 5 to 9 "tokens", roughly word pieces, per second). This is how Othos was built and tested.
  • A graphics card with 8 GB: small models run faster, and fully offline speech becomes possible but tight.
  • 12 to 16 GB graphics memory: 8 to 14 billion-parameter models and comfortable offline speech.
  • 24 GB and up: the largest models Othos suggests (about 27 to 32 billion parameters).

The project README has a full table by graphics card and laptop. These figures are estimates, not promises, and your numbers will differ. On Windows, Ollama uses NVIDIA cards out of the box; AMD support covers only some cards; Intel Arc and Snapdragon graphics are not used by standard Ollama, so models run on the processor. Before you buy anything, check Ollama's GPU list.

Two people on one computer

If two people use one Windows PC with separate Windows accounts, each account has its own Othos folder, settings, drafts, keys, Ollama and models. But the whole computer shares the local addresses (ports), the processor, memory and graphics card. While one account's Othos is running, the other's either cannot start or ends up using the first account's Ollama.

Best practice: close Othos and its helpers, then fully sign out of Windows (Start, your account picture, Sign out) before the other person signs in. Do not use Switch user, which leaves the first account's programs running.

Customising

  • Conversation model: OLLAMA_MODEL in agent\.env. Download it first, for example ollama pull qwen3:8b.
  • Voice: RIME_SPEAKER (cloud) or LOCAL_TTS_VOICE (offline). Respellings for words it says wrongly go in agent\pronunciations.json, and place names in personal.json.
  • Gaming mode: agent\gaming.json lists your games and what each one needs.
  • Packages stay pinned. After you install or upgrade a Python package yourself, run agent\update-requirements.ps1.
